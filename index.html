Phase 1: Exploring Digital Media


Making 1

In Making 1 I coded a website about who I am using a given template. This assignment was completely foreign to me. Although, simple I was very proud of my ability to navigate the code and curate my website to reflect who I am. I figured out how to add photos to my folder and then assign them a place on my website through the code.

Making 2

In Making 2 I was really inspired to create some sort of "game." I decided that tennis would be the game. Admittedly, a lot of this website was programmed by AI but I did understand how some of the coding was made. I used Ai to create the code and I "copy-pasted certain" sections of the code into specifec areas in my code.

Making 3

For Making 3 I wanted to make another website about me but from my own coding. I learned from my last website that I wouldn't get very far if I kept on depending on AI to do the code for me because I wouldn't ever understand what the AI was coding for me. For this multipage website I was very proud with my own coding and ability to work through my obstacles by being a "pro hacker." I successfully made a website all about my favorite things with working buttons to take the user to information slides. I went into the code and I made my website, for things like the size of pictures, I was unsure how to change that. I asked CoPilot to help me edit the size of one picture and once it did that I learned from that code and was able to then change the size of my other photos. I think that this was my biggest learning experince out of the 3 "Making" projects.

Phase 1 Course Goals


1. Foster the creative habits of mind

In Making 1, I learned how to use code to build a website that represented who I am. Even though I started with a given template, I learned to adjust the HTML and CSS to fit my vision. I figured out how to add my own photos and assign them spots on my page, which made the site more personal. This process showed me that coding is a creative tool, not just a set of strict rules. Each time I tested changes and saw them work, I gained confidence to experiment and trust my ideas.

2. Engage with others in a workshop environment.

Throughout Phase 1, I worked with classmates to troubleshoot problems and share ideas. For example, during Making 2, I created a tennis-themed game with some help from peers who shared tips about JavaScript organization. In return, I explained parts of my HTML setup to others. Talking through these challenges helped me understand coding concepts better. The workshop setting made the learning process feel collaborative instead of stressful.

3. Think deeply about craft.

By Making 3, I realized how small details shape how a website works and feels. In that project, I wrote most of the code myself without relying on AI. I paid attention to things like button placement, image size, and navigation flow. When one image was too large, I used CoPilot to figure out how to adjust it and then applied that knowledge to the rest of my site. This taught me that thoughtful, precise coding makes a big difference in user experience.


4. Engage in sustained research and skills development.

Across all three projects, I had to research how specific tags and commands worked. In Making 1, I looked up how to insert photos. In Making 2, I learned how to embed interactivity into a game structure. By Making 3, I was solving problems independently by reading documentation and experimenting with my code. This steady practice showed me that progress in coding comes from patience and consistent effort.

5. Learn to present your work

Sharing my projects helped me see my work from others’ perspectives. In class, I explained how each website functioned and what I learned from building it. For Making 3, I presented how I coded buttons and structured multiple pages, focusing on clarity instead of technical jargon. Presenting my sites this way built my confidence and helped me communicate my ideas in a simple, clear way.
